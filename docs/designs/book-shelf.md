## Vision

### 10x Check
Не журнал покупок, а память о чтении, которая отвечает сама: в магазине перед покупкой («вы уже слушали это в 2024»), в разговоре с ассистентом через MCP и в итогах года. Данные уже собираются для полки, поэтому сверху это примерно 2x усилий.

### Platonic Ideal
Ни одной книги не вбито руками. Литрес синкается по кнопке и раз в месяц, Kindle-покупки приходят письмами, история и статусы Kindle берутся из выгрузки Amazon и входа по запросу. Одна книга из двух магазинов - одна запись с обложкой. «Поделиться» со страницы книги сразу отвечает, читал ли я её. Ассистент знает полку.

- Ответ «читал/нет» в шорткате «Поделиться», добавление в «хочу» по подтверждению.
- Повторяемый идемпотентный импорт выгрузки Amazon со статусом и датами из сессий чтения, ручной статус не перетирается.
- MCP-инструменты: поиск, добавить в «хочу», статистика. Remote Streamable HTTP, OAuth 2.1 (D10).

- Блокирующие проверки до кода: API Литрес (P4) с fallback на «Поделиться», реальные письма и выгрузка Amazon как фикстуры.
