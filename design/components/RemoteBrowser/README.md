# RemoteBrowser

Экраны входа через браузер на сервере: «Sync Kindle» с 2FA и капча Литрес. Человек видит живую трансляцию браузера и вводит данные сам, пароль не сохраняется.

**Шаги по порядку:**
1. **Раскрытие.** «Вы входите в Amazon в браузере на нашем сервере.» и три факта (`bs-facts`): пароль не сохраняется, сессия удаляется после синка, за кодом 2FA можно уйти. «Продолжить» и «Отмена».
2. **Очередь** (если браузеры заняты). Тот же лист: «Браузер занят, вы следующий» и позиция в очереди.
3. **Подключение.** Скелетон браузера в `bs-session__view`.
4. **Вход.** Трансляция 390px на весь экран, системная клавиатура. Сверху таймер 5:00 (`bs-session__timer`, `role="timer"`) с полоской остатка времени: задайте `--left` в процентах на `bs-session__bar`. Последняя минута - `bs-session__timer--low`. «Отменить» всегда виден. Ушли в другое приложение за кодом - при возврате переподключаемся к той же сессии, таймер продолжает идти.
5. **Сбор данных.** Шаги с иконками `done` и `progress` (`is-pending`), `aria-live`. Можно уйти, результат придёт баннером.
6. **Результат.** «+12 книг, 40 хайлайтов» или причина: «Сессия прервана, войдите снова», «Время вышло», «Amazon не пустил вход».

**Что передаёт потребитель:** поток трансляции, оставшееся время, шаги сбора, итог.

**Не делайте:** не рисуйте поверх трансляции свой интерфейс Amazon. Не прячьте «Отменить». Не просите пароль в своём поле.
