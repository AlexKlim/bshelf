# EntryForm

Ручное добавление книги, оформленное как запись на странице: человек вписывает название от руки, выбирает формат и статус, «Записать» ставит книгу на нужную полку.

**Что передаёт потребитель:** поля «Название», «Автор», «Когда» (необязательное), выбор формата (Аудио, Книга) и статуса (Хочу, На полке, Читаю или Слушаю, Прочитал или Прослушал). Подпись статуса меняется по выбранному формату. Ошибки дубля приходят с сервера и показываются у поля названия.

**Когда использовать:** кнопка «Добавить книгу» есть на шкафу всегда, не только в пустом состоянии. Ответ «Не на полке» из поиска и шортката открывает эту же форму с подставленным названием.

**Делайте:** вписанный текст только шрифтом `hand` цветом `pen`. Подписи полей шрифтом `ui`. Ошибку пишите у поля с `aria-describedby`. Чипы - настоящие radio внутри `fieldset` с `legend`.

**Не делайте:** не делайте форму из рамочных полей. Не прячьте ошибку дубля в тост. Не ставьте вторую главную кнопку.
