# Shelf

Полка шкафа: задняя стенка, ряд корешков, планка с латунной табличкой, плюс подпись над полкой для выдвинутой книги.

**Что передаёт потребитель:** название полки и число книг для таблички («Сейчас · 3», «2025 · 18»), список корешков (`Spine`) в порядке полки. Полки собираются в `bs-case` сверху вниз: «Сейчас», «Хочу», годы по убыванию, «Без даты».

**Разметка:** `section.bs-shelf` с `h2.bs-shelf__plaque`, `ul.bs-shelf__row` и `div.bs-shelf__plank`. Заголовок идёт первым в DOM, CSS сам ставит табличку на планку.

**Подпись над полкой** (`bs-caption`): на телефоне после первого касания по корешку показывается над полкой рядом с книгой. Внутри название, автор и `StatusMark`. Касание по подписи открывает книгу так же, как второе касание по корешку. На десктопе подписи нет, наведение выдвигает книгу, клик открывает.

**Делайте:** длинная полка листается вбок, правый край тает. Пустая полка «Хочу» показывает `bs-shelf__empty` «Пока пусто». Стрелки двигают фокус вдоль полки, вверх и вниз между полками.

**Не делайте:** не переносите корешки на вторую строку. Не прячьте табличку при прокрутке. Не ставьте больше одной подписи над шкафом.
