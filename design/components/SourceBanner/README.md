# SourceBanner

Единственный слот сообщений над шкафом: ошибка источника или одно событие, которое ждёт человека.

**Что передаёт потребитель:** текст (что случилось, коротко), одно действие (`bs-btn--quiet`), кнопку «Скрыть» для сообщений, которые можно закрыть. Ошибка источника не закрывается, пока её не исправят.

**Приоритет слота:** ошибка источника (`bs-banner--error`, `role="alert"`) > выгрузка готова > напоминание войти в Литрес > возможные дубли (все `bs-banner--notice`, `role="status"`). Закрытое сообщение не возвращается до следующего события. Остальное живёт в «Источниках».

**Тексты:** «Литрес не пустил вход: неверный пароль.» + «Войти снова». «Пора обновить полку: войдите в Литрес.» + «Войти». «Нашлись возможные дубли: 3.» + «Посмотреть». «Нет сети. Шкаф показан из кэша.» без действия.

**Не делайте:** не показывайте два баннера сразу. Не используйте баннер для успеха синка, результат «+12 книг» показывается на месте кнопки синка.
