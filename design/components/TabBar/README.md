# TabBar

Три раздела приложения: «Шкаф», «Статистика», «Источники».

**Что передаёт потребитель:** текущий роут. Это навигация `nav` со ссылками, у текущей `aria-current="page"`, не Radix Tabs: вкладки ведут на разные экраны, а не переключают панели на одном.

**Раскладка:** до 1200px панель снизу (`bs-tabs`), с отступом под домашний индикатор. От 1200px сверху (`bs-tabs--top`). «Профиль» не вкладка, он открывается по аватару в шапке.

**Не делайте:** не добавляйте четвёртую вкладку. Не ставьте счётчики на вкладки, ошибки источников показывает баннер над шкафом.
