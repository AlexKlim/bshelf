# EmptyCase

Первый экран после регистрации: пустые полки и лист с тремя способами наполнить шкаф.

**Устройство:** `div.bs-empty` кладёт друг на друга пустой `bs-case` (две полки без корешков, `aria-hidden`) и лист `section.bs-onboard` на `page-paper` с путями `bs-path`.

**Пути, по порядку:**
1. «Войти в Литрес» - главная кнопка, полка наполняется сразу. Подпись «Пароль не хранится».
2. «Запросить историю Kindle» - открывает инструкцию по запросу выгрузки у Amazon. После запроса кнопка неактивна, подпись показывает ожидание: «Запрошено 25 октября. Amazon готовит архив, обычно 1-3 дня.» Когда архив готов, об этом скажет баннер над шкафом.
3. «Добавить книгу» - тихая кнопка, открывает `EntryForm`.

**Когда убирать:** лист исчезает, как только на полке появилась первая книга. Кнопка «Добавить книгу» остаётся на шкафу всегда.

**Не делайте:** не превращайте пути в три одинаковые карточки. Не ставьте вторую главную кнопку. Не пишите «Добро пожаловать».
