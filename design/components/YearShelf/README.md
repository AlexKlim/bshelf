# YearShelf

«Полка года» на экране статистики: итог одной строкой и двенадцать стопок корешков по месяцам вместо графиков и плиток с цифрами.

**Что передаёт потребитель:** год и переключение на соседние годы, итог («2025: 18 книг · 11 слушал · 7 читал»), книги по месяцам с тканью и форматом, число книг без даты, топ авторов.

**Правила:** высота стопки - число книг, каждая книга лежит корешком (`bs-stack__book` с тканью из того же правила, что и на полке) с иконкой формата. Стопка - кнопка с `aria-label` «Март: 3 книги». На телефоне касание по стопке открывает список книг месяца в подписи над полкой, на десктопе клик по книге открывает разворот. Книги без даты не попадают в месяцы, они строкой «Без даты» под полкой.

**Состояния:** год без книг - пустая полка и «Пока нет прочитанных в 2026». Загрузка - стопки `spine-blank`.

**Не делайте:** не добавляйте круговые диаграммы, графики и плитки с крупными числами.
