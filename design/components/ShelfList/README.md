# ShelfList

Вид «Список»: те же полки и книги, но строками. Это доступная альтернатива шкафу для тех, кому корешки неудобны.

**Устройство:** переключатель «Шкаф / Список» из `bs-choices` над шкафом, выбор запоминается. Каждая полка - `section.bs-list` с липким заголовком `h2.bs-list__head` («2025 · 18») и списком кнопок `bs-row`. В строке маленький корешок `bs-row__spine` в ткани книги, название, автор и `StatusMark`.

**Что передаёт потребитель:** те же данные, что шкафу: полки по порядку, книги с тканью, статусом, форматом и датой.

**Делайте:** нажатие на строку открывает тот же `BookSpread`. Внутри полки статус можно сократить до месяца («Прослушал · март»), год уже стоит в заголовке. Стрелки вверх и вниз двигают фокус по строкам.

**Не делайте:** не меняйте порядок полок относительно шкафа. Не превращайте строки в карточки.
