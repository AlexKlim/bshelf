# StatusMark

Строка статуса книги: иконка статуса или формата и текст «Статус · дата» из общего словаря.

**Что передаёт потребитель:** статус (Хочу, На полке, Читаю или Слушаю, Прочитал или Прослушал), формат издания (от него зависит форма глагола), дату, уже отформатированную через `Intl`. Иконка статуса - `bs-ico-want|owned|progress|done`. Когда важнее формат (подпись над полкой, ответ поиска), вместо иконки статуса ставьте `bs-status__formats` с одной или двумя иконками формата.

**Варианты:** обычный `bs-status` (`ink-muted`) и `bs-status--strong` (`ink`) для текущей книги и изданий на развороте.

**Не делайте:** не красьте статусы цветом, статус кодируют полка, иконка и слово. Не придумывайте синонимы вне словаря из README.
