# SearchField

Поиск «Читал ли я…» над шкафом, который отвечает одной строкой прямо под полем.

**Что передаёт потребитель:** запрос, результат поиска и обработчики кнопок «Хочу», «Читал», «Слушал» для случая «Не на полке».

**Поведение:** поле стоит первым на экране шкафа, под большим пальцем. Пока человек печатает, совпавшие корешки получают `is-match` на своих полках. Под полем строка `bs-answer` с ответом по таблице из README («Слушали · март 2024», «Похожие: 2 книги», «Не на полке»). Из «Не на полке» до записи книги не больше двух касаний: «Хочу» записывает сразу, «Читал» и «Слушал» открывают `EntryForm` с подставленным названием.

**Делайте:** `type="search"`, шрифт 17px (`search-input`). Ответ в `role="status"`, чтобы скринридер его прочитал.

**Не делайте:** не уводите на отдельную страницу результатов. Не показывайте ответ карточкой.
