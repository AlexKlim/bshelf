# Button

Кнопка действия в трёх весах: `bs-btn--primary`, `bs-btn--secondary`, `bs-btn--quiet`, плюс мелкий размер `bs-btn--sm`.

**Что передаёт потребитель:** текст действия глаголом («Войти в Литрес», «Записать», «Синхронизировать»), при желании иконку `bs-ico` перед текстом.

**Правила:** одна `primary` на экран. `secondary` для действий в строках «Источников». `quiet` для ссылочных действий и действий внутри баннера и разворота. Во время запроса ставьте `aria-busy="true"` и меняйте текст на процесс («Синхронизирую…»). Высота всегда не меньше `touch-min`, даже у `sm`.

**Не делайте:** не добавляйте кнопкам тени и градиенты. Не пишите «ОК» и «Да», называйте действие.
