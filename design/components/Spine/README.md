# Spine

Корешок книги на полке: ткань, вертикальное название и автор, иконка формата внизу.

**Что передаёт потребитель:** название, автор, язык книги (`lang`), ткань (`bs-cloth--<имя>` по правилу из README), ширину и высоту через `--spine-w` и `--spine-h`, форматы (одна или две иконки), `aria-label` вида «Название, автор. Статус, дата».

**Состояния:**
- покой - без модификаторов
- выдвинут - `is-pulled` или `aria-expanded="true"` (первое касание на телефоне, наведение на десктопе)
- найден поиском - `is-match`
- узкий - `bs-spine--narrow`, автор скрыт
- загрузка - `is-loading` на `bs-cloth--blank`, без текста, `aria-hidden`

**Делайте:** корешок - `button`. Второе нажатие на выдвинутый корешок открывает книгу. Язык ставьте по книге: русский текст повернётся снизу вверх.

**Не делайте:** не ставьте цвет обложки напрямую, только восемь тканей. Не пишите на корешке статус и дату, они в подписи над полкой. Не делайте корешок ниже `touch-min`.
